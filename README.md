# Sushanth Reddy — Portfolio

> Personal developer portfolio built with React, TypeScript, and Vite.

## 🌐 Portfolio


The portfolio showcases my projects, technical skills, achievements, education, coding profiles, and an interactive AI-powered portfolio assistant.

## ✨ Features

- Modern futuristic developer-focused UI
- Responsive design for desktop, tablet, and mobile
- Interactive project showcase
- Project detail views
- Skills and achievements sections
- Education and contact sections
- Resume access
- GitHub, LinkedIn, LeetCode, CodeChef and Codeforces integration
- **Sushanth's Copilot** — interactive AI portfolio assistant
- Smooth animations and micro-interactions
- Keyboard-accessible navigation and interactions

## 🛠️ Tech Stack

- React
- TypeScript
- Vite
- CSS
- Node.js / APIs where required
